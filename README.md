# 訪問型ミドルシニア専用エステサロン「おうちでニコット」予約サイト

TECH-BASEというインターンに参加して制作したサイトです。
開発のアイデアは、母が運営するエステサロンの予約管理の非効率さを目の当たりにしたことに端を発しています。
事業のデジタル化と効率化への貢献を目指し、本プロジェクトに着手しました。

このプロジェクトは、「サロンへの移動が身体的に負担である」と感じるミドルシニア世代が抱える、
「自宅外での施術に伴う移動時間と労力の課題」を解決するために開発しました。

### 現状の課題
・ミドルシニア層（50〜70代前後）は、体力や移動の制約によりサロンへの来店が難しい
・エステやリラクゼーションサービスの予約は電話が中心で、営業時間外の対応や管理が不十分
・介護美容やリラクゼーション目的のサービスは、個人の健康状態や希望に合わせた予約管理が難しい
・利用者の生活や健康状態、希望の施術内容を一元管理できる仕組みが少ない

### 解決できる課題
・「訪問型エステ」をオンライン予約で簡単に申し込み可能にする
・利用者の希望や体調に合わせた施術内容・時間を事前に管理者が確認できる
・管理者が訪問スケジュールを一覧で管理でき、重複や過不足を防止
・利用者の体調や好みに合わせたカスタマイズ予約が可能

### 今後の目標
・TypeScript や AWS を学習し、よりスケーラブルなサービス開発に挑戦したいです。
・パフォーマンスやセキュリティを意識したコードを書き、実務に近い水準で開発を進めたいです。
